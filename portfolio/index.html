BYU Assignment Hub

A mobile-friendly academic planning dashboard that brings coursework from BYU Canvas and Learning Suite into one place—assignments, readings, deadlines, planning, and focus tools.

View source on GitHubSee the interface
What it does

One place to plan the week.

Unified coursework

Combines active Canvas assignments with Learning Suite coursework and scheduled readings.

Planning tools

Supports course filtering, calendar views, completion tracking, a Next Up queue, and focus-session planning.

Built for daily use

Responsive mobile navigation and PWA support make the dashboard usable across desktop and phone.

Interface

Desktop to mobile.

Development approach

AI-assisted, product-directed.

I developed Assignment Hub to solve a problem in my own academic workflow. I direct the product requirements, interface behavior, testing, debugging, and iteration while using AI coding tools to assist with implementation. The project continues to evolve through real-world daily use.
